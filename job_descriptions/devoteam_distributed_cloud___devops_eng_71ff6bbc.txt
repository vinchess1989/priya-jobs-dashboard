Job Description


Contribute to the design of a secure, scalable and robust infrastructure code base;
Continuously improve our CI/CD automation to speed up the deployment cycles;
Continuously improve our cloud infrastructure logging/auditing capabilities;
Collaborate with our Engineering team to identify and solve issues and tasks that can be automated.



Qualifications


Expertise in managing and using DevOps Tools such Terraform and Kubernetes;
Some knowledge of Public Cloud Services;
Expertise on containerized applications using containers or Docker (BuildKit/buildx);
Expert-level scripting skills using PowerShell, Bash and/or Bash;
Proficient with Windows and Linux OS;
Experience in Kubernetes/Openshift based Microservices architectures and technologies;
Experience with Apache Kafka;
Experience adopting Agile methodologies like Scrum;
Good verbal and written communication skills;
Problem-solving attitude;
Collaborative team spirit.
