Räätälöi ansioluetteloni
We build things that work, scale, and matter

At Futurice, we bring together software engineering, cloud infrastructure, design, and emerging tech to create lasting impact. We solve hard problems for prominent Nordic organizations—not through dogmatic processes, but through trust, pragmatic engineering, and continuous learning.

About The Role

We are looking for a Senior Cloud & DevOps Engineer with deep public cloud automation expertise. In this role you will be helping our clients navigate high-scale cloud transformations and production AI initiatives in complex, potentially highly regulated environments.

You don't need to be an AI researcher or machine learning scientist. If you have solid enterprise cloud foundations, love automating platform infrastructure, and want to build the operational backbone that takes generative AI applications from prototype to regulated production, this role is for you.

What You’ll Be Doing


Automating enterprise cloud platforms: Design, deploy, and maintain secure, production-grade public cloud infrastructure (hub-and-spoke topologies, landing zones, networking, and zero-trust identity).
Treating everything as code: Build and standardize modular Infrastructure as Code using Terraform or Bicep, managed through automated CI/CD pipelines (GitHub Actions or Azure DevOps or similar).
Powering enterprise AI enablement: Help build and run shared developer platforms—such as managing API gateways for centralized routing, quota tracking, logging, and access control.
Streamlining developer workflows: Enable client product teams by providing reusable infrastructure templates, CI/CD blueprints, and automation scripts in Python or TypeScript.
Bringing production rigor to AI (LLMOps): Collaborate on operationalizing generative AI systems—setting up observability, tracing, cost monitoring, and security guardrails.


What We Hope You Bring


Deep public cloud experience (AWS, Azure or GCP): Practical experience with enterprise public cloudenvironments, virtual networking, private endpoints, access management, and landing zones.
Strong IaC & CI/CD mastery: Extensive, hands-on experience deploying infrastructure using Terraform or Bicep through automated pipelines.
Software & scripting skills: Practical programming ability in Python (or TypeScript/Go) for automation, API integrations, and internal tooling.
Operational mindset: Familiarity with modern observability, log aggregation, and monitoring in mission-critical environments.
Curiosity for modern AI tooling: You are eager to roll up your sleeves with tools like Azure OpenAI, API Management, RAG pipelines, or LLM observability frameworks. (Direct prior experience is a huge plus, but strong fundamentals and willingness to learn take priority.)
A consultant’s pragmatism: You enjoy helping teams solve practical problems, communicate trade-offs clearly, and care about developer experience.
Language skills: Professional working proficiency in English is required, as it is our primary working language. Professional proficiency in Finnish is considered a strong advantage when collaborating with local enterprise and public-sector clients.
