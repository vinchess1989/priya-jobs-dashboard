At Verda, we're building a full-stack AI cloud, covering everything from data centers and hardware to our own cloud platform that the world's leading AI teams use to do serious AI work.

Join Verda while it’s still being built - not once it’s finished.

Why Verda


Cash and equity compensation along with local benefits.
40+ nationalities, with 6 different ones on the management team.
A real chance to make an impact and work alongside world class engineers, researchers, and partners across the global AI ecosystem.


What You'll Do


Build and maintain unified testing frameworks for API, integration, E2E, and regression testing across multiple engineering teams.
Define the test strategy across layers (unit, component, contract, API/integration, and E2E) and decide which checks belong in which layer, pushing coverage down to the cheapest layer that reliably catches the bug.
Design and own the test flow and promotion gates: which suites block a merge request, which gate promotion from dev → staging → production, and which run on a schedule, so that a green result can be trusted to promote a release automatically.
Establish reusable testing standards, templates, and automation that developers can independently adopt.
Build initial automated test suites for critical services and workflows, helping development teams extend and maintain them.
Develop automated smoke tests, release validation, and post-deployment checks to catch regressions early.
Integrate automated testing into GitLab CI/CD, GitHub Actions, and deployment pipelines.
Add performance checks to the test flow: track API latency and database query time against agreed budgets, and flag regressions before promotion (e.g. slow-query detection in component tests, k6 checks on staging).
Build and maintain test environments (including ephemeral and containerized environments for component tests), test data, and supporting infrastructure.
Improve test reliability, execution speed, reporting, and visibility into release quality.
Research and implement AI-assisted testing tools and automation to improve testing efficiency.
Collaborate with development teams to identify testing gaps and improve overall software quality.


What We're Looking For


3+ years of experience in Quality Engineering, Test Automation, SDET, or Software Engineering.
Strong programming skills in Python, Go, TypeScript, or JavaScript.
Hands-on experience building automated testing frameworks for APIs, integration tests, and E2E workflows.
Experience designing a test strategy or test pyramid and making trade-offs between coverage and pipeline speed.
Experience building release gates or promotion pipelines that rely on automated test results.
Experience with tools such as Playwright, pytest, Jest, Vitest, or similar.
Strong understanding of CI/CD, Git, Linux, containers, and modern software development practices.
Experience testing microservices, APIs, and distributed applications.
Ability to build reusable tooling and automation that supports multiple teams and programming languages.
Strong troubleshooting, problem-solving, and collaboration skills.
Interest in AI-assisted testing and engineering workflows.


Nice to Have


Experience with Kubernetes and containerized testing environments.
Familiarity with ArgoCD and GitOps, including progressive delivery (e.g. Argo Rollouts).
Experience with performance and load testing using k6, Locust, or similar.
Experience with contract testing (Pact or similar) and component testing with real dependencies (e.g. Testcontainers).
Experience building ephemeral test environments and automated release validation.
Familiarity with observability tools such as Prometheus and Grafana.
