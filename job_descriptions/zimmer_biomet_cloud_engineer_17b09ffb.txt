At Zimmer Biomet, we believe in pushing the boundaries of innovation and driving our mission forward. As a global medical technology leader for nearly 100 years, a patient’s mobility is enhanced by a Zimmer Biomet product or technology every 8 seconds.

As a Zimmer Biomet team member, you will share in our commitment to providing mobility and renewed life to people around the world. To support our talent team, we focus on development opportunities, robust employee resource groups (ERGs), a flexible working environment, location specific competitive total rewards, wellness incentives and a culture of recognition and performance awards. We are committed to creating an environment where every team member feels included, respected, empowered and recognised.

What You Can Expect

We are looking for a motivated and detail-oriented Cloud Engineer to support the provisioning, configuration, and maintenance of cloud infrastructure within our Microsoft Azure environment. In this hands-on role, you will work alongside experienced engineers to automate deployments, manage containerized workloads, and contribute to secure, scalable, and efficient cloud operations. This is an excellent opportunity for a technically curious individual eager to build a career in cloud engineering.

How You'll Create Impact


Provision, configure, and maintain Azure cloud resources across development, QA, staging, and production environments.
Implement and maintain infrastructure using Infrastructure as Code (IaC) tools such as Bicep and ARM templates, following established standards and approval processes.
Monitor cloud environments for performance, availability, cost optimization, and application health using Azure Monitor, Azure Log Analytics, and Azure Application Insights.
Assist in analyzing logs, metrics, traces, and alerts to support incident response, root cause analysis, and continuous improvement.
Participate in day-to-day cloud operations including incident response, change management, access reviews, and cloud resource tagging.
Deploy, operate, and support containerized applications on Azure Kubernetes Service (AKS) with an emphasis on secure-by-default and safety-focused configurations.
Support AKS safety and security features including:
Role-Based Access Control (RBAC) and least-privilege access
Network policies and private cluster configurations
Pod and container security best practices
Cluster and workload observability using logs, metrics, and alerts
Patch management and Kubernetes version upgrades under guidance
Perform scaling, health monitoring, and basic troubleshooting of Kubernetes workloads using kubectl, Helm, and Azure CLI.
Contribute to CI/CD workflows and deployment automation in collaboration with developers using GitHub Actions, with attention to deployment safety, validation, and rollback strategies.
Create and maintain documentation for cloud infrastructure, deployment processes, observability standards, security controls, and operational procedures.
Participate in agile ceremonies including sprint planning, retrospectives, and internal knowledge-sharing sessions.

Your Background


Bachelor’s or Master’s degree in Engineering, Computer Science, or a related field, or equivalent practical experience.
Working knowledge of Microsoft Azure and core services such as Virtual Machines, App Services, Storage, Networking, and identity services.
Practical understanding of Kubernetes fundamentals (pods, deployments, services, namespaces) and container orchestration concepts.
Experience using Docker and container deployment tools such as Helm.
Familiarity with application monitoring and observability tools, including Azure Monitor, Azure Log Analytics, and Azure Application Insights.
Experience with scripting or automation using PowerShell, Bash, or programming languages such as Python or C#.
Understanding of cloud security fundamentals including RBAC, identity management, network segmentation, and least-privilege principles.
Ability to follow defined processes and controls while progressively taking ownership of assigned systems and tasks.
Strong communication skills and a collaborative, team-oriented mindset.


Travel Expectations


Occasional overnight travel as necessary.


This is a full-time position and it may reasonably require additional hours during the week and weekend; specific requirements will be determined with Manager.
