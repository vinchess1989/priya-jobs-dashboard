Räätälöi ansioluetteloni

We are looking for a Software Security Engineer to join our Software Architecture Team within R&D in Seinäjoki, Finland.

The role focuses on implementing the EU Cyber Resilience Act (CRA) requirements and integrating security into the software development lifecycle through SSDLC, DevSecOps practices, automated testing, and CI/CD processes.




Key Responsibilities

Develop and improve security testing and automation practices;
Implement security controls within CI/CD pipelines;
Support secure software development in a .NET environment;
Contribute to vulnerability management and remediation activities;
Support CRA compliance through processes and documentation;
Collaborate with software development teams in an international environment.




Requirements

Experience with .NET software development;
Knowledge of CI/CD pipelines, test automation, or security tools;
Interest in DevSecOps and Application Security;
Experience with GitHub and GitHub Actions is an advantage;
Fluent English.




Nice to Have

Experience with SAST, SCA, or DAST tools;
Experience with Aikido Security / Aikido Dev.
