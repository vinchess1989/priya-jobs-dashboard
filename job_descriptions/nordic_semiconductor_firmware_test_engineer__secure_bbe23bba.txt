About the job

Join our R&D organisation in Oulu and help us verify the embedded firmware that keeps Nordic's chips secure. The secure domain firmware is low-level code running on the chip itself: it is the first thing that executes when the device powers up and the foundation everything else relies on, covering secure boot, device lifecycle, firmware updates and key handling. Making sure it behaves correctly, every time, is what this role is about.

As a Firmware Test Engineer you will build and run the automated tests and CI pipelines that catch problems before they reach silicon or customers. The code under test runs on resource-constrained hardware, and much of your test code runs on the target alongside it. You will work closely with the firmware developers who own the code you are testing. This is a good opportunity for someone early in their career: we care more about your testing mindset, your programming skills and your curiosity than about the number of years on your CV, and you will have experienced colleagues around you to learn from.


Key responsibilities

Write and maintain automated tests for secure domain firmware, from unit level up to tests running on real silicon.

Write embedded test code in C that runs on the target, and build test scripts, tools and frameworks in Python.

Maintain and extend our CI pipelines (Jenkins), and keep builds and nightly test runs trustworthy.

Set up and look after test hardware in the lab, such as development kits, debuggers and automated test setups.

Investigate failing tests and write clear bug reports together with the developers.

Contribute to test plans and test coverage for new firmware features.



Key Qualification and skills

Bachelor's or Master's degree in Computer Science, Software Engineering, Electrical Engineering, or a related technical field. A study track or specialisation in cyber security or information security is a plus.

Good C and Python skills: C for embedded code running on the device, Python for test automation on the host side.

Good understanding of software testing: test design, test automation, and unit, integration and system level testing.

Working knowledge of git and CI systems such as Jenkins or GitHub Actions.

Comfortable using modern AI-assisted development tools in day-to-day work.

Knowledge of Zephyr or another RTOS is an advantage.

Knowledge of secure software concepts such as secure boot, cryptography or key management is an advantage.

Knowledge of pre-silicon environments such as emulation or FPGA platforms is an advantage.



Personal Skills

The ideal candidate is systematic and curious, and enjoys the detective work of figuring out why something failed. You are not satisfied with "it works on my machine", and you like automating the boring parts away. You communicate clearly, ask questions when something is unclear, and are eager to learn about embedded systems and security from the people around you.

About Nordic Semiconductor

Nordic Semiconductor is a Norwegian fabless semiconductor company specializing in wireless communication technology that powers the Internet of Things (IoT). Nordic was established in 1983 and has about 1400 employees across the globe. Our award-winning Bluetooth Low Energy solutions pioneered ultra-low power wireless, making us the global market leader. Our technology range was later supplemented by ANT+, Thread and Zigbee, and in 2018 we launched our low power, compact LTE-M/NB-IoT cellular IoT solutions to extend the penetration of the IoT. The Nordic portfolio was further complemented by Wi-Fi technology in 2021.
