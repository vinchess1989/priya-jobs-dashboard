About the job




Who We Are We are looking for a DevOps / Cloud Infrastructure Engineer to take ownership of the design, automation, security, deployment, and operation of our production infrastructure.This is a hands-on role for someone who is comfortable working across the full infrastructure stack — from cloud networking and Linux systems to Docker, CI/CD, databases, monitoring, security, and production troubleshooting.You will work closely with our engineering team and technical leadership to build secure, reliable, and highly automated development, staging, and production environments.

This position is based in either Heraklion, Crete or Athens, Greece.




What You’ll Do




As a DevOps Engineer, you will:

Design, provision, and maintain cloud infrastructure on AWS, GCP, and/or Azure.
Build infrastructure using Terraform and automate server configuration and deployments with Ansible.
Design secure cloud networks including VPC/VNet, private/public subnets, routing, NAT, firewalls, VPNs, DNS, and private services.
Manage and harden Linux-based production environments.
Containerize and operate applications using Docker, Docker Compose and/or Docker Swarm.
Design and maintain GitHub Actions CI/CD pipelines for building, testing, containerization, and deployment.
Manage DNS, SSL/TLS certificates, reverse proxies, and load balancers such as Nginx, or cloud-native solutions.
Deploy and operate MySQL and PostgreSQL databases securely within private networks.
Implement monitoring, centralized logging, alerting, backups, health checks, and recovery procedures.
Troubleshoot production issues across the complete stack: application, container, server, network, database, and cloud.
Improve infrastructure reliability, security, scalability, and automation.
Maintain technical documentation, deployment procedures, and operational runbooks.




 What We're Looking For




3+ years of hands-on experience in DevOps, Infrastructure Engineering, Systems Engineering, Cloud Engineering, or a similar role.
Strong experience with at least one major cloud platform: AWS, GCP, or Azure.
Strong hands-on knowledge of Terraform and Infrastructure as Code principles.
Experience with Ansible or similar configuration-management tools.
Strong Linux administration and troubleshooting skills.
Strong understanding of TCP/IP, HTTP/HTTPS, DNS, routing, NAT, firewalls, proxies, and load balancing.
Strong practical knowledge of Docker and containerized application deployments.
Experience building and maintaining GitHub Actions CI/CD pipelines.
Experience with SSL/TLS certificate management and automation.
Practical knowledge of MySQL and PostgreSQL, including backups, permissions, networking, and performance troubleshooting.
Experience implementing monitoring, logging, and alerting using tools such as Prometheus, Grafana, Loki, ELK/OpenSearch, CloudWatch, Azure Monitor, or Google Cloud Operations.
Strong understanding of infrastructure security, including least privilege, network segmentation, SSH hardening, secrets management, and secure private deployments.
Ability to troubleshoot complex production issues and perform root-cause analysis.
Strong communication skills and the ability to collaborate effectively with software engineers and technical leadership.




Application Knowledge




You do not need to be a full-time software developer, but you should be comfortable understanding how modern applications operate in production.Experience with or understanding of Node.js, React, environment configuration, application processes, logging, API communication, caching, background workers, and database connectivity is important.Working knowledge of Sequelize ORM is a plus.You should be comfortable troubleshooting problems across:Application → Container → Server → Network → Cloud




What success Looks Like




The ideal candidate should be able to take a system from:Source Code → GitHub → CI/CD → Docker → Infrastructure → Private Networking → DNS → SSL/TLS → Load Balancing → Application Deployment → Database → Monitoring → Security → Backup & Recoveryand be capable of automating, securing, monitoring, troubleshooting, and maintaining the complete production environment.




Nice to Have




Experience managing 24/7 production systems.
Experience with high-availability and disaster-recovery architectures.
Kubernetes experience.
Experience with secrets-management platforms.
Cloud security or infrastructure security experience.
Experience with cloud cost optimization.
Experience with SRE practices, SLAs/SLOs, and incident management.
Relevant cloud, Linux, security, or infrastructure certifications.




About You




You are someone who prefers automation over repetitive manual work, treats infrastructure as code, thinks about security from the beginning, and takes ownership of production systems.You are comfortable investigating unfamiliar problems, making technical decisions, documenting your work, and continuously improving the reliability and maintainability of the platform.If you enjoy building infrastructure from the ground up and owning systems from architecture through production operations, we’d like to hear from you.
